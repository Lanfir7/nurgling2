# 2.103.205

## Русский

- В окне «Что нового» появился поиск по подробностям прошлых обновлений. Подходящие выпуски показываются с раскрытым текстом.
- Окна макросов и ботов запоминают своё положение после перемещения.
- Увеличенные кнопки под миникартой и значок большой карты принимают нажатие по всей увеличенной области.

## English

- What's new now searches the details of past updates and expands matching entries.
- Macro and bot windows remember where you moved them.
- Enlarged minimap overlay buttons and the Map icon accept clicks across their enlarged area.
