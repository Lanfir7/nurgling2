# 2.103.206

## Русский

- Обычный клиент и Nurgling Evolution в Steam используют общий источник обновлений.
- Существующие способы запуска продолжают работать. Стандартные BAT-загрузчики переводятся на новый адрес при обновлении; для старых установок сохранены прежние ссылки.
- Подписка Steam, профили, карты и настройки сохраняются. Переустанавливать клиент не требуется.

## English

- The standalone client and Nurgling Evolution on Steam use a shared update source.
- Existing launch methods continue to work. Standard batch launchers receive the new address during updates; legacy links remain available for older installations.
- Steam subscriptions, profiles, maps and settings are preserved. No reinstall is required.

## Release operations

`master` is the development and release branch. `next`, `nurgling-release/latest`
and `nurgling-release/stable` remain compatibility feeds with the same prepared
artifacts. The existing Steam Workshop item is updated in place.
